# Repay Tech Debt — manual usage

Quick reference for humans and agents. All paths use `<skill-root>` (directory containing
`SKILL.md`) and `<target-root>` (canonical application repository root).

## Skill activation flags

When you invoke the skill with a flag (e.g. in chat: “use repay-techdebt `--clear-output`”), the
agent runs the matching script **before** analysis. These map to `project-memory.js` actions.

| Flag / intent    | Script         | What it does                                                                                                                            |
| ---------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `--clear-output` | `clear-output` | Removes skill memory, workbook (`INDEX.md`, `progress.json`, lessons), curriculum, and artifacts. **Never** deletes application source. |
| `--clear-cache`  | `clear-cache`  | Removes disposable analyzer cache only (Graphify/Serena indexes). Keeps lessons and curriculum.                                         |
| `--reset`        | `reset`        | `--clear-output` plus `--clear-cache`. Fresh skill state for the target.                                                                |
| `--reconfig`     | `reconfig`     | Updates preferences in existing `config.json` (mode, depth, save policy, hints). Does not move workbook paths.                          |
| `--view`         | `open-viewer`  | Opens the script-owned workbook viewer in the browser (`view-lessons.js --open`).                                                       |
| `--create <id>`  | `teach-topic`  | Start teaching one planned topic by id, title slug, or focus (`teach-topic.js`).                                                        |

Optional modifiers (combine with clear/reset):

| Modifier                  | Effect                                                                                                                |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`               | Preview paths that would be removed; no deletes.                                                                      |
| `--keep-lessons`          | Delete curriculum, progress, and index state but keep `lessons/*.md`.                                                 |
| `--keep-config`           | Clear output and curriculum but keep `config.json`.                                                                   |
| `--revert-target-markers` | Remove `.repay-techdebt/` from `.gitignore` and `.graphifyignore`; delete target-local `.repay-techdebt/` if present. |

Every destructive action requires consent: preview (exit 2) then `--yes`.

## Maintenance commands

### Clear skill output (fresh workbook)

```text
node <skill-root>/scripts/project-memory.js clear-output <target-root> --dry-run
node <skill-root>/scripts/project-memory.js clear-output <target-root> --yes
```

Keeps lesson markdown only:

```text
node <skill-root>/scripts/project-memory.js clear-output <target-root> --keep-lessons --yes
```

Also revert target ignore markers (project-local / team memory):

```text
node <skill-root>/scripts/project-memory.js clear-output <target-root> --revert-target-markers --yes
```

### Clear analyzer cache

```text
node <skill-root>/scripts/project-memory.js clear-cache <target-root> --yes
```

### Full reset (output + cache)

```text
node <skill-root>/scripts/project-memory.js reset <target-root> --dry-run
node <skill-root>/scripts/project-memory.js reset <target-root> --yes
```

### Reconfigure preferences

```text
node <skill-root>/scripts/project-memory.js reconfig <target-root> \
  --mode workbook --depth balanced --save-policy ask --yes
```

Interactive terminal wizard:

```text
node <skill-root>/scripts/project-memory.js reconfig <target-root> --interactive
```

### Open workbook viewer

The viewer UI is **always** generated by scripts (`src/viewer/` + `viewer.css`). Agents must not
hand-build HTML.

Discoverable workbooks (sister/custom) include a `README.md` with the same commands — you can open
the viewer without an AI agent:

```text
node <skill-root>/scripts/view-lessons.js <target-root> --open
```

Also:

```text
node <skill-root>/scripts/project-memory.js open-viewer <target-root>
node <skill-root>/scripts/view-lessons.js <target-root> [--port 8765] [--open] [--lesson lessons/...]
```

After `save-lesson`, the emit includes `viewer.script`, `viewer.deepLinkRel`, and
`viewer.openRecommended` (open browser when true — after 3rd lesson or batch complete).

### Teach one planned topic (`--create`)

Chat activation (recommended): `/repay-techdebt --create topic-abc123`. Planned topics in the
viewer show this command on their placeholder page — create the lesson in chat with your agent.

Script (agents / automation only):

```text
node <skill-root>/scripts/teach-topic.js <target-root> <topic-id-or-slug> [--draft <path>]
```

### Skill runtime

After skills.sh sync, `node_modules` may be missing. CLIs auto-run `ensure-runtime` (installs into
`<skill-root>` only). Manual: `node <skill-root>/scripts/ensure-runtime.js`.

### Session stepper

Agents follow `templates/agent-experience.md`: **progress table** at top, **one blank line between
tables**, one lead line before asks, ≤10 words outside tables on routine turns, `👉 Reply` on asks.
See `SKILL.md`.

## What maintenance never touches

- Application source files, tests, and configs the skill did not create
- `package.json`, lockfiles, or dependencies (unless you separately asked for installs)
- Arbitrary `.gitignore` lines unrelated to `.repay-techdebt/`

## Typical flows

**Fresh start on a project**

1. `clear-output --dry-run` → review plan
2. `reset --yes` (or `clear-output --revert-target-markers --yes` if markers matter)
3. `init … --yes` (wizard / introduction flow)

**Stale analyzer data only**

1. `clear-cache --yes`
2. Re-run analysis scripts

**Change defaults without wiping lessons**

1. `reconfig --depth concise --save-policy automatic --yes`

**Read lessons in browser**

1. `open-viewer <target-root>` or `view-lessons.js <target-root> --open`
